# Мастер-класс «Как модель видит данные»

Комплект материалов для 90-минутного занятия со школьниками 9–10 классов.

## Цель мастер-класса

Показать ровно ту часть математики, которая помогает понять базовое линейное вычисление в Machine Learning, без отдельного курса линейной алгебры.

Главная цепочка занятия:

```text
реальный объект
→ признаки
→ вектор
→ много объектов
→ матрица X
→ shape
→ веса w
→ скалярное произведение
→ X @ w + b
→ prediction
```

Авиационный кейс в notebooks является упрощённым учебным примером. Признаки, веса и результаты нельзя использовать как реальную модель посадки или управления воздушным движением.

## Файлы

- `01_math_for_ml_students.ipynb` — рабочая тетрадь ученика без ответов и преподавательских заметок.
- `01_math_for_ml_teacher.ipynb` — сценарий преподавателя с вопросами, решениями, типичными ошибками и запасными объяснениями.
- `README_01.md` — описание комплекта и план проведения.

Оба notebooks рассчитаны на Google Colab, не используют локальные файлы, API или интернет и выполняются сверху вниз.

## Learning outcomes

После занятия ученик сможет:

- объяснить, почему модель получает числовые признаки, а не сам реальный объект;
- различать один объект (`vector`) и набор объектов (`matrix`);
- читать `shape` как «объекты × признаки»;
- объяснить роль `weights` и `bias` простыми словами;
- вычислить маленькое скалярное произведение вручную;
- объяснить смысл `x @ w + b` для одного объекта;
- объяснить смысл `X @ w + b` для нескольких объектов;
- связать вычисление с основой простого искусственного нейрона или линейного слоя;
- распознать несовместимые размеры данных и весов.

Главный критерий — ученик понимает смысл выражения `X @ w + b`, а не просто копирует строку кода.

## Prerequisites

Ученик должен уметь:

- запускать ячейки в Google Colab;
- читать простой Python-код;
- работать со списком чисел на базовом уровне;
- выполнять обычное умножение и сложение.

Не требуются:

- линейная алгебра;
- pandas;
- обучение моделей;
- производные, градиенты или backpropagation.

## Подготовка преподавателя

1. Открыть `01_math_for_ml_teacher.ipynb` в Google Colab.
2. Запустить `Runtime → Run all` и убедиться, что ошибок нет.
3. Сделать отдельную копию `01_math_for_ml_students.ipynb` для класса.
4. Проверить, что школьники могут открыть копию и запускать ячейки.
5. Держать на проекторе teacher notebook, а ученикам раздать student notebook.

Импорты `numpy`, `pandas` и `matplotlib` находятся в первой основной code cell. Все данные создаются внутри notebook.

## Полный тайминг

| Время | Блок | Результат |
|---|---|---|
| 0–10 мин | Зачем модели математика | Объект нужно представить числовыми признаками |
| 10–25 мин | Вектор признаков | Один объект представлен одним вектором |
| 25–40 мин | Матрица данных | Строка — объект, столбец — признак, `shape` описывает структуру |
| 40–55 мин | Веса | Каждому признаку соответствует вес |
| 55–65 мин | Скалярное произведение | Взвешенные признаки объединяются в одно число |
| 65–72 мин | Bias | К взвешенной сумме добавляется смещение |
| 72–78 мин | Простой нейрон | Формула связана с линейным слоем |
| 78–83 мин | Матрица и много объектов | `X @ w` применяет вычисление ко всем строкам |
| 83–88 мин | Мини-эксперимент | Изменение весов меняет outputs |
| 88–90 мин | Финал | Ученик объясняет всю цепочку своими словами |

Итого: 90 минут. Если класс идёт медленнее, сначала сокращайте дополнительные и challenge-задания, а не объяснения основных понятий.

## Понятия

- `feature` — числовой признак объекта;
- `feature vector` / `vector` — упорядоченный набор признаков одного объекта;
- `matrix` — данные нескольких объектов;
- `dataset` — набор примеров для работы модели;
- `shape` — размеры массива;
- `weights` — параметры, определяющие вклад соответствующих признаков в вычисление;
- скалярное произведение — умножение соответствующих элементов с последующим сложением;
- `bias` — дополнительное смещение результата;
- `prediction` — результат вычисления модели.

На занятии намеренно не вводятся определители, обратные матрицы, ранг, собственные числа и векторы, SVD, СЛАУ, производные, градиенты, gradient descent, backpropagation и сложные activation functions.

## Практические задания

### 🟢 Базовые

- создать вектор для условного рейса;
- вывести вектор и определить `shape`;
- получить строку и столбец матрицы;
- сопоставить признаки и веса;
- вычислить `x @ w`;
- изменить bias;
- сопоставить predictions со строками матрицы;
- объяснить `X @ w + b` словами.

### 🟡 Дополнительные

- изменить один признак или один вес;
- добавить объект и предсказать новый `shape`;
- сделать вес нулевым;
- подобрать bias для заданного результата;
- сравнить outputs для нескольких наборов весов.

### 🔴 Challenge

- добавить новый признак и согласованно изменить веса;
- объяснить ошибку несовместимых `shape`;
- удалить признак и корректно пересобрать данные и веса.

Challenge не требует неизвестной высшей математики.

## Как использовать teacher notebook

Каждый блок начинается со сценария:

- вопрос аудитории до объяснения;
- ответ, который не нужно выдавать сразу;
- ожидаемый ответ;
- ключевая мысль;
- материал для проектора;
- практика;
- типичная ошибка;
- более простое объяснение;
- дополнительный вопрос;
- тайминг.

Рабочий цикл: задать вопрос, выслушать гипотезы, коротко объяснить идею, показать 2–6 строк кода, попросить предсказать результат, запустить ячейку, дать ученикам изменить данные и обсудить изменение.

Решения находятся только в teacher notebook. Числовые outputs следует называть условными `score`, `output` или `prediction`, но не реальным временем посадки.

## Как раздать student notebook

Предпочтительный вариант:

1. Загрузить student notebook в Google Drive преподавателя.
2. Открыть доступ только на просмотр по правилам школы.
3. Дать ученикам ссылку.
4. Попросить выбрать `File → Save a copy in Drive`, чтобы каждый работал в своей копии.

В student notebook TODO-ячейки безопасны: незаполненное задание не мешает последующим ячейкам выполняться сверху вниз.

## Мост к следующей паре по Computer Vision

На этом занятии школьники вручную проходят путь от признаков до prediction. На следующей паре изображение станет реальным объектом, а готовая Computer Vision модель сама построит большое числовое представление и выполнит множество операций с обученными весами.

Финальная связка для преподавателя:

> Сегодня мы разобрали базовое вычисление руками. В реальном проекте библиотеки и готовые модели скрывают большую часть математики, но данные всё равно превращаются в числа и проходят через вычисления с весами. На следующей паре используем готовую Computer Vision модель и соберём AI-приложение.

## Техническая проверка

Перед занятием оба notebooks нужно выполнить сверху вниз. Ожидаемые ключевые результаты:

- `x.shape == (4,)`;
- `X.shape == (4, 4)`;
- ручной результат `0.74` совпадает с `flight @ weights`;
- после `b = 0.1` prediction равен `0.84`;
- `X_normalized @ weights + b` имеет `shape == (4,)`;
- демонстрация несовместимых размеров перехватывает ошибку и не останавливает notebook.
